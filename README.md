# Happy Birthday, Varshini (Boori) 💗

A responsive interactive birthday website with **8 screens**.

## Files

- `index.html` — all 8 screens
- `style.css` — styling and responsive layout
- `script.js` — screen navigation and interactions
- `photo-1.jpg` through `photo-5.jpg` — replaceable sample images

## Upload to GitHub

1. Extract this ZIP.
2. Upload **all files inside this folder** to the root of your GitHub repository (not the ZIP itself).
3. Keep the filenames exactly as shown above, including lowercase letters.
4. Open **Settings → Pages**. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. After deployment, hard-refresh the published page with `Ctrl + Shift + R`.

## Add your photos

The five included images are sample placeholders so the site runs immediately. Replace them with your own photos, keeping the exact filenames `photo-1.jpg` through `photo-5.jpg`.

## Confirm all 8 screens

The counter should show `01 / 08` on the first screen. Use the on-screen buttons to move through the experience. The final screen includes a replay button.
